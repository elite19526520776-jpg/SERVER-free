# Realistic Textures / 写实材质包

Minecraft Java 版资源包，**113 个方块 × 64×64**（原版是 16×16），每个方块都带 LabPBR 1.3 的
法线图和高光图。配合光影包能吃到凹凸、金属反射和自发光。

A resource pack: **113 blocks at 64×64** (vanilla is 16×16), each with LabPBR 1.3 normal and
specular maps so a shader pack can render real bump, metal and emission.

---

## 安装 / Install

把这个文件夹（或它的 zip）丢进 `.minecraft/resourcepacks/`，在**选项 → 资源包**里启用。

- 不装光影也能用，只是只有反照率生效（画面依然比原版细腻 4 倍）。
- 装了光影（Iris / OptiFine + 支持 LabPBR 的光影）才会读法线和高光图。
- 本仓库的 [`RealisticShaders`](../RealisticShaders) 就是配套的光影包。

> 法线/高光图需要在光影设置里开启 **PBR / LabPBR**。OptiFine 用户还需要
> **视频设置 → 品质 → 自定义材质 = 开**。

## 材质是怎么来的 / How the textures are made

全部由 [`tools/generate_pack.py`](tools/generate_pack.py) 程序化生成，**不依赖任何第三方库**
（PNG 直接用 `zlib` 编码）：

```bash
python3 tools/generate_pack.py            # 重新生成全部
python3 tools/generate_pack.py --only ore # 只生成名字含 "ore" 的
```

用到的手法：

- **值噪声 + 分形叠加**做岩石、泥土、沙子的自然颗粒（噪声网格环绕采样，保证可无缝平铺）
- **Voronoi 元胞**做圆石和沙砾的碎块分割，缝隙压暗
- **错缝砌体算法**做砖块和石砖，砂浆缝下陷
- **正弦木纹 + 板缝**做木板，**同心圆**做年轮，**竖向沟壑**做树皮
- **矿脉结核**：在母岩上嵌噪声打碎边缘的矿物团，而不是规整的圆点
- **织纹交叠**做羊毛的经纬

法线图和 AO 不是画的，是从**高度场推导**的：法线取高度的中心差分，AO 取「高度 − 模糊后的高度」
当作缝隙遮蔽。所以砂浆缝、木纹、石块边缘的凹凸和阴影天然对齐。

### 通道约定 / Channel layout (LabPBR 1.3)

| 文件 | R | G | B | A |
|---|---|---|---|---|
| `<name>.png` | 反照率 | | | 透明度 |
| `<name>_n.png` | 法线 X | 法线 Y | 环境光遮蔽 | 高度 |
| `<name>_s.png` | 感知光滑度 | F0 / 金属索引 | 孔隙度 / 次表面 | 自发光 |

几个容易踩的点，脚本里都按规范处理了：

- `_s` 的 alpha 写 **255 表示「没有自发光数据」**，不是「自发光为 0」。写错整个世界会发光。
- F0 通道 **230–237 是预定义金属**（230 铁、231 金、234 铜），238–255 是「用反照率当 F0」的通用
  金属。铁块/金块/铜块和对应矿石都写了正确的索引。
- 草方块顶面、覆盖层和树叶必须是**灰阶**——游戏会按生物群系给它们染色，先上色就会叠成两层绿。

## 改成你自己的风格 / Retexturing

每个方块在 `build_registry()` 里就是一行，改色标就能换风格。比如想要更冷的石头：

```python
reg["stone"] = lambda: grainy(
    [(0.0, (78, 84, 92)), (0.45, (108, 116, 124)), (1.0, (150, 158, 164))],
    seed=11, base=4, octaves=5, grain=22, smoothness=0.05, porosity=0.10)
```

`grainy` / `rubble` / `masonry` / `planks` / `bark` / `metal` / `wool` / `ore` 这些配方函数都带
PBR 参数，改完重跑脚本即可。
