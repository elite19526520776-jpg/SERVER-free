# 方块世界 · VoxelCraft

一个在浏览器里运行的 Minecraft 类沙盒游戏。**无限地形**、**20 种生物群系**、
**全部材质由程序化算法实时生成**（不含任何图片/音频素材文件），
WebGL2 + 法线贴图 + 昼夜光照。

整个游戏是纯前端的，没有后端、没有依赖、没有构建步骤。

---

## 怎么玩

### 方式一：双击打开（推荐）

打开 `dist/voxelcraft.html` 即可。这是把所有代码打包进去的单文件版本，
可以直接双击、也可以拖进浏览器窗口，不需要架服务器。

### 方式二：从源码运行

因为用的是 ES 模块，`file://` 协议会被浏览器的跨域策略拦住，需要一个静态服务器：

```bash
cd game
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080/
```

改完源码后重新生成单文件版：

```bash
node build.mjs        # → dist/voxelcraft.html
```

### 环境要求

需要支持 **WebGL2** 的浏览器（Chrome / Edge / Firefox / Safari 16+ 都可以）。
首次进入时会有几秒钟在生成材质和地形，属于正常现象。

## 操作

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| `W A S D` | 移动 | `E` | 打开/关闭背包 |
| `空格` | 跳跃 / 上浮（水中、飞行） | `Q` | 丢弃物品（`Shift+Q` 丢一组）|
| `Shift` | 潜行 / 下降 | `1`–`9` / 滚轮 | 切换快捷栏 |
| `Ctrl` | 疾跑 | `F` | 生存 / 创造模式互切 |
| 左键 | 挖掘 / 攻击 | `G` | 创造模式物品栏（可搜索）|
| 右键 | 放置 / 使用 / 交互 | `T` | 白天 ⇄ 夜晚 |
| 中键 | 选取准星所指的方块 | `+` / `-` | 调整视距（3–16 区块）|
| 双击空格 | 创造模式切换飞行 | `F3` | 调试信息 |
| `Esc` | 关闭界面 | `F5` | 第一/第三人称 |
| `F1` | 操作说明 | `R` | 立即存档 |

存档写在浏览器 `localStorage`，每 60 秒自动保存一次，关闭页面时也会保存。
换浏览器或清缓存会丢档。

## 内容一览

### 世界生成

- **无限地形**：以区块（16×128×16）为单位随玩家移动流式加载/卸载，
  已在距原点 ±100 万格处验证过生成正常。
- **气候参数化群系**：由大陆度、侵蚀度、温度、湿度、奇异度五张噪声图共同决定，
  因此群系边界是自然过渡而不是硬切。
- **20 种生物群系**：海洋、深海、河流、沙滩、石岸、平原、繁花平原、森林、
  繁花森林、白桦森林、黑森林、针叶林、雪原针叶林、雪原、冰刺之地、山地、
  雪山、沙漠、热带草原、丛林、沼泽、恶地、蘑菇岛。
- **地貌**：山脉（脊状噪声）、河流下切、海岸线、恶地的分层陶瓦。
- **洞穴**：3D 噪声雕刻的「意面洞穴」+「奶酪大厅」，深处有岩浆湖。
- **矿脉**：煤、铁、铜、金、红石、青金石、钻石、绿宝石，各自有深度分布区间。
- **植被**：11 种树形（橡树、大橡树、白桦、高白桦、云杉、高云杉、丛林树、
  巨型丛林树、金合欢、深色橡树、沼泽橡树），以及草、蕨、6 种花、蘑菇、
  仙人掌、甘蔗、南瓜、枯萎的灌木，按群系分布。

### 玩法

- **生存 / 创造**双模式，创造模式可飞行、无限取用。
- **挖掘**：方块硬度 × 工具等级决定耗时；工具不对口只能挖不掉落。
- **合成**：2×2 随身合成 + 3×3 工作台，**100+ 条配方**，支持有序 / 无序配方与材料标签
  （比如任意木板都能做木棍）。
- **熔炉**：烧炼矿石、食物、沙子、黏土；燃料按物品的燃烧时长计算，带火焰与进度条。
- **箱子**：27 格存储，`Shift` 点击快速存取。
- **物品**：150+ 种方块 + 工具（5 材质 × 5 类型）+ 全套盔甲（4 材质 × 4 部位）
  + 食物 + 材料，共 230 余种。
- **生存要素**：生命、饥饿、饱和度、护甲减伤、溺水、摔落伤害、岩浆、仙人掌、
  自然回血、饿死、死亡与重生。
- **生物**：猪、牛、羊、鸡（被动，会逃跑）；僵尸、骷髅、苦力怕、蜘蛛（敌对）。
  按光照等级与昼夜刷新，成群出现，僵尸骷髅白天会燃烧，骷髅射箭，
  苦力怕靠近后倒计时爆炸并炸出坑洞。
- **物理**：AABB 碰撞、自动上台阶、游泳、爬梯子、冰面打滑、沙砾掉落。
- **流体**：水和岩浆有真正的流动等级（水最远 7 格、岩浆 3 格），会往低处流、
  会断流回收；水碰岩浆生成石头/圆石/黑曜石。桶可以装水、倒水。
- **光照**：天空光与方块光两套 15 级光照，跨区块洪水填充传播；
  平滑光照（顶点插值）+ 环境光遮蔽。

### 渲染

- 每个方块材质都会生成三张图：**基础色**、**由高度场求得的法线**、**粗糙度/金属度**，
  上传为 WebGL2 的 `TEXTURE_2D_ARRAY`（从根本上消除图集渗色）。
- 光照模型：天空光 + 方块光 + 太阳直射漫反射 + GGX 高光 + 环境光遮蔽 + 各向异性过滤。
- 天空是实时计算的：日出日落染色、星空、绕天顶运行的日月、程序化云层。
- 水面有顶点波浪、法线扰动、菲涅尔反射天空，水下有独立的雾与滤镜。
- 生物是分部件的长方体模型，皮肤同样由噪声程序化生成，带头部朝向与四肢摆动。
- 物品图标：方块画成等距立方体（取三个面的真实贴图），工具/食物用矢量程序化绘制。
- 音效：全部用 WebAudio 实时合成（挖掘、放置、脚步、受伤、爆炸、弓箭……），无音频文件。

## 已知取舍

这是一份从零手写的实现，和正版 Minecraft 相比有意省略了下面这些：

- 没有红石电路、附魔、酿造、村庄、要塞、下界与末地。
- 没有多人联机（纯本地单机）。
- 世界高度是 128 格（正版是 384 格）。
- 台阶只有下半砖，没有楼梯、栅栏、门这类需要复杂朝向数据的方块。
- 农作物没有生长阶段，种下即可收获。
- 曲奇、南瓜派的配方用小麦/糖替代了可可豆和鸡蛋（游戏里没有这两样材料）。
- 距原点超过约 10 万格后，32 位浮点精度会让画面出现轻微抖动
  （这是体素游戏的通病，正版同样存在）。
